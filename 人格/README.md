## 💡 使用指南

1. **原始文件查阅**：如需查看 GitHub 上的初始未经处理的 prompt 文件，请查阅 `raw_templates/`。
2. **多角色激活/部署**：标准化角色卡带有统一的 YAML Frontmatter 元数据和结构化定义，可直接复制或引用至各智能体系统（如 Hermes Agent、WorkBuddy、Codex CLI、Dify、FastGPT 等）的 System Instructions 中使用。
3. **小说创作入口**：写小说直接用 **26 文枢**（总控，自动路由笔法与工序）；需要单一能力拉满时，再单独加载 12–25 中的对应专项卡。
